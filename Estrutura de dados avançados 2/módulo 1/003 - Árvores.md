## Definição:

Estrutura de dados que organiza os dados no formato de uma árvore de cabeça pra baixo.

**Componentes:**
- Nó raiz 
- Cada nó pode ter filhos
- Um nó possui um pai (exceto a raiz)

![[Pasted image 20260419183410.png]]


## Tipos de árvores:

### 1. Árvore binária
- **Cada nó tem até 2 filhos**
- Filho esquerdo
- Filho direito

### 2. Árvore binária de busca
- Valores menores ficam na esquerda
- Valores maiores ficam na direita
- **Permite buscar mais rápido pelo dado**

![[Pasted image 20260419183945.png]]


## Percurso da árvore

### 1. Pré-ordem:
- Raiz → esquerda → direita

![[Pasted image 20260419191455.png]]

![[Pasted image 20260419191526.png]]


### 2. Em ordem

- Esquerda → raiz → direita
- **Basicamente: gera uma lista crescente**

![[Pasted image 20260419191702.png]]


### 3. Pós-ordem

- **Os filhos sempre vêm antes do pai.**
- Esquerda → direita → raiz
