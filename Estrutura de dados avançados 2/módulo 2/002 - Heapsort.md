
## Funcionamento:

O heapsort sempre preenche um array com o resultado ordenado. Porem possui um detalhe muito importante, ele sempre preenche o array **da direita para a esquerda.**

**Max-heap:** extrai do maior para o menor → preenche o array da direita para a esquerda. Resultado **ascendente.**

**Min-heap:** extrai do menor para o maior → preenche o array da direita para a esquerda. Resultado **descente**

**Importante:** a direção de preenchimento (direita → esquerda) é sempre a mesma nos dois casos. O que muda é **quem esta sendo extraído primeiro.**
