
## Definição

Quando os polos são complexos, para evitar toda a algebra complexa das frações parciais. É utilizado o método de completar quadrados.
O objetivo é tornar as frações idênticas às fórmulas de laplace para seno e cosseno

![[Pasted image 20260529003812.png]]

### Exemplo:

### $$s^2 + 6s + 25$$
**Completar quadrado - passos:**

- Olhar para o termo que acompanha o s. No caso o 6.
- Dividir por 2. $\frac{6}{2}$ = 3
- Montar a base do quadrado perfeito: $(s+3)^2$ 
- Verificar quanto falta para ter o 25. : 25 - 9 = 16
- Reescrever o denominador com o termo que foi encontrado
