
## Definição:

- REST é um padrão de comunicação para sistemas que utilizam HTTP

## Métodos HTTP

### GET
**Definição:** Busca por dados. Em uma API REST, o método GET pode retornar uma lista contendo informações.

### POST
**Definição:** método responsável pela criação de novos dados.

### PUT
**Definição:** responsável por atualizar registros.

### DELETE
**Definição:** remove registros

### PATCH
**Definição:** atualização parcial
