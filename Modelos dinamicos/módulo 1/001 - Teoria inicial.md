
## Sistemas dinâmicos / modelos


### Sistema:

→ Grupo de componentes que trabalham em conjunto para realizar uma tarefa

### Sistemas dinâmicos:

→ Sistemas que evoluem e mudam sua configuração com o tempo.
→ Usado para modelar vários tipos de situações. Ex: mecânico, eletrônico, térmico, econômico, etc.
→ Não possuem soluções exatas
→ Encontrar os parâmetros que afetam a dinâmica do sistema

### Modelagem

→ Processo para se obter equações matemáticas que determinam o comportamento do sistema com base no tempo.
→ Tenta representar matematicamente a forma mais precisa do comportamento de um sistema real.

### Variáveis de estado

→ Definem o estado de um sistema. Permitem identificar as configurações do sistema em cada instante. (Ex: temperatura da geladeira, é possível identificar e regular a temperatura).


### Modelos físicos x Modelos matemáticos:

**Físico:** se assemelham ao sistema real, porem são mais simples, matem as características mais importantes.

**Matemático:** representação matemática por meio de equações, elas buscam representar o comportamento dinâmico do sistema.
