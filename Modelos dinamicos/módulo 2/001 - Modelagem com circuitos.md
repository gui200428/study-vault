
## Componentes:

### Resistores

![[Pasted image 20251104143146.png]]

**Unidade:** Ω
**Formula: (para tensão)**

### $$e_R=R*i$$
**Formula: (para corrente)**

### $$i=\frac{e_R}{R}$$

**Sendo:**
$e_R$ = tensão sobre o resistor.
$R$ = resistência
$i$ = corrente


### Capacitores

![[Pasted image 20251104143602.png]]

**Unidade:** F

**Formula: (para tensão)**

### $$e_c=\frac{Q}{C}$$

**Formula: (para corrente)**

### $$i=C\dot{e_c}$$

**Sendo:**
$e_c$ = tensão sobre o capacitor
Q = carga
C = capacitância


### Indutores

![[Pasted image 20251104144224.png]]

**Unidade:** H

**Formula: (para tensão)**

### $$e_L=L\frac{di}{dt}$$

**Formula: (para corrente)**

### $$i=\frac{1}{L}\int e_L \ dt$$

**Sendo:**

$e_L$ = tensão sobre o indutor
$L$ = indutância
$i$ = corrente

## LKT / LKC


### LKT - lei das malhas:

→ Aplicada para cada malha do circuito
→ A somatória das quedas de tensões ao redor de uma malha deve ser zero.
→ **Convenção de sinal:** 
- Queda de tensão → sinal positivo
- Aumento de tensão → sinal negativo

**Definir sentido positivo (arbitrário) para a corrente**

- Queda de tensão ocorre quando se vai + → - em um componente.
- No final a somatória dos aumentos e quedas de tensão será nulo.


### LKC - lei das correntes

→ Aplicada para cada nó do circuito.
→ A somatória das correntes que entram e saem de um nó é igual a zero.

entrando = saindo

correntes que entram em um nó são consideradas positivas e as que saem, são negativas.
