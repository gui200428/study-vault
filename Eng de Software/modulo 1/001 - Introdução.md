
## O QUE É SOFTWARE ?

**Software** é um produto **conceitual e lógico** formado pelos elementos necessários para que um computador execute determinadas funções.

Segundo **Pressman (2021)**, o software envolve:

- **Instruções/programas:** executam as funções e produzem o desempenho esperado.
- **Estruturas de dados:** permitem armazenar e manipular informações.
- **Informações descritivas/documentação:** explicam a operação e o uso do programa.

Segundo **Sommerville (2011)**, software pode ser entendido como um conjunto de **soluções algorítmicas**, escritas em uma **linguagem de programação** e executadas em uma máquina real.

> **Resumo:** Software é um **produto lógico** composto por programas, dados e documentação para realizar determinadas funções.

**Software = programas + dados + documentação**  
**Software = produto lógico, não físico**

### Software na Engenharia de Software

Na **Engenharia de Software**, o software inclui não apenas o código executável, mas também os artefatos necessários para seu **desenvolvimento, entendimento, teste e manutenção**.

Isso pode incluir **documentação de requisitos, diagramas de arquitetura, planos de teste e manuais**.
### Atributos de um bom software
Um bom software não precisa apenas **funcionar**. Ele também deve apresentar características de qualidade.

|Atributo|Em linguagem humana|
|---|---|
|**Funcionalidade**|Faz corretamente aquilo para o qual foi criado.|
|**Confiabilidade**|Funciona de forma consistente e consegue lidar adequadamente com falhas.|
|**Usabilidade**|É fácil de aprender, entender e utilizar.|
|**Eficiência**|Executa suas tarefas usando bem **tempo e recursos** como memória e processamento.|
|**Manutenibilidade**|É fácil de corrigir, modificar e melhorar.|
|**Portabilidade**|Pode ser adaptado ou executado em diferentes plataformas e ambientes.|
|**Reusabilidade**|Partes do software podem ser aproveitadas em outros sistemas ou partes do próprio sistema.|
|**Escalabilidade**|Consegue suportar crescimento de usuários ou dados sem perder desempenho de forma significativa.|
|**Segurança**|Protege o sistema e os dados contra acessos e alterações não autorizadas.|

### Evolução histórica do software

A evolução do software acompanha a mudança dos computadores: de máquinas enormes e especializadas para sistemas pessoais, gráficos e conectados pela Internet.

#### 1940–1950 — Mainframes e primeiros softwares

Os primeiros computadores, como **ENIAC** e **UNIVAC**, eram grandes, caros e voltados principalmente para **cálculos científicos e militares**.

Os programas eram escritos em **linguagens de baixo nível**, muito próximas do hardware, e normalmente feitos para tarefas bastante específicas.

> **Resumo:** Primeiros softwares = baixo nível + hardware específico + cálculos especializados.

> **1940–50 = máquinas enormes + software especializado**

### Computadores pessoais

Com a popularização dos **computadores pessoais**, o software passou a atingir usuários comuns e pequenas empresas.

Sistemas como **MS-DOS** e **Apple DOS** ajudaram nesse processo, enquanto aplicações como **editores de texto** e **planilhas eletrônicas** passaram a fazer parte do cotidiano.

O **VisiCalc** é citado como um dos primeiros grandes exemplos de planilha eletrônica para computadores pessoais.

> **Resumo:** PCs popularizaram o software para uso pessoal e comercial.


PCs = software sai do laboratório → chega ao usuários

### Sistemas operacionais gráficos

Na década de **1980**, interfaces gráficas passaram a transformar a interação com os computadores.

Em vez de depender apenas de comandos de texto, o usuário passou a interagir através de **janelas, ícones e menus**, tornando os sistemas mais intuitivos.

O material destaca a influência do **Xerox PARC** e exemplos como **Apple Lisa, Mac OS e Windows**.

> **Resumo:** Interfaces gráficas tornaram os computadores mais fáceis e acessíveis.


### Internet e Software Livre

Na década de **1990**, a popularização da **Internet** aumentou a conectividade e permitiu novas formas de distribuição, comunicação e colaboração através do software.

Navegadores como **Netscape Navigator** e **Internet Explorer** ajudaram a levar a Web ao público geral.

Nesse período também ganhou força o movimento de **software livre**, com projetos como **GNU** e **Linux**, defendendo liberdades como **usar, estudar, modificar e distribuir software**.

> **Resumo:** Internet trouxe conectividade; software livre trouxe maior liberdade sobre o código.


### Netscape Navigator

> **Netscape Navigator = exemplo de navegador importante na popularização da Web nos anos 1990**


### Aplicativos móveis e computação em nuvem
A partir dos anos 2000, o software passou a ser cada vez mais utilizado em **dispositivos móveis** e através da **computação em nuvem**.

Os aplicativos móveis se popularizaram principalmente com as lojas de aplicativos, permitindo instalar diversos serviços diretamente em smartphones.
Já a **computação em nuvem** permite armazenar e acessar dados e serviços através da Internet, facilitando o **acesso remoto** e o **trabalho colaborativo**.

**Exemplos:** Google Drive e Dropbox.

> **Resumo:** Aplicativos móveis levaram software aos smartphones; a nuvem permitiu acessar dados e serviços pela Internet.


### Tendências atuais e futuras
O desenvolvimento de software está incorporando cada vez mais tecnologias como **Inteligência Artificial (IA)**, **Aprendizado de Máquina**, **Realidade Aumentada (AR)** e **Realidade Virtual (VR)**.

A **IA** permite criar sistemas capazes de oferecer automação, assistência e experiências mais personalizadas, como **assistentes virtuais e chatbots**.

Já **AR e VR** permitem experiências mais **interativas e imersivas**.

> **Resumo:** O software moderno incorpora IA, aprendizado de máquina, AR e VR para criar sistemas mais inteligentes e interativos.


## Campos de aplicação do software

Segundo **Pressman (2021)**, existem **7 grandes categorias de software**.

### Software de Sistema

**Software de sistema** é desenvolvido principalmente para **dar suporte a outros programas** e controlar ou oferecer serviços relacionados ao funcionamento do computador e de seus recursos.

**Exemplos:** sistemas operacionais, compiladores, drivers, softwares de rede e componentes de telecomunicações.

> **Resumo:** Software de sistema fornece suporte e serviços para outros softwares e para o funcionamento do computador.

### Software de Aplicação

São programas criados para resolver uma **necessidade específica do usuário ou de uma organização**.

Normalmente processam informações para apoiar **operações, atividades comerciais ou tomada de decisões**.

**Exemplo:** sistema financeiro, sistema de vendas ou sistema de gestão empresarial.

> **Resumo:** Software de aplicação resolve uma necessidade específica do usuário ou negócio.

### Software de Engenharia/Científico
São softwares voltados para **cálculos, simulações e análises técnicas ou científicas**, geralmente envolvendo grande quantidade de processamento matemático.
**Exemplos:** meteorologia, análise genética, dinâmica orbital, projetos auxiliados por computador e simulações de engenharia.

> **Resumo:** Software científico realiza cálculos e análises técnicas complexas.


### Software Embarcado
É um software que fica **integrado a um equipamento ou produto**, controlando funções específicas desse dispositivo.

Pode realizar uma função simples ou controlar partes importantes do sistema.

**Exemplos:** software de um micro-ondas, painel de um automóvel ou sistema de freios.

> **Resumo:** Software embarcado é integrado ao equipamento para controlar suas funções.


### Software para Linha de Produtos
É desenvolvido a partir de **componentes reutilizáveis** para criar produtos semelhantes destinados a **vários clientes ou usuários**.

Em vez de desenvolver tudo novamente, uma base comum pode ser reutilizada e adaptada para diferentes produtos.

**Exemplo:** uma família de sistemas de controle de estoque adaptada para empresas diferentes.

> **Resumo:** Linha de produtos reutiliza uma base comum para criar softwares semelhantes.

> **Linha de produtos = mesma base → vários produtos**


### Aplicações Web / Aplicativos Móveis
São softwares desenvolvidos para ambientes **conectados em rede**, incluindo aplicações executadas em navegadores, serviços em nuvem e aplicativos instalados em dispositivos móveis.

**Exemplos:** sistemas Web, serviços em nuvem e aplicativos para smartphones.

> **Resumo:** Aplicações Web/móveis são softwares voltados para redes, navegadores, nuvem ou dispositivos móveis.


### Software de Inteligência Artificial
São softwares voltados para problemas complexos que utilizam técnicas como **heurísticas, reconhecimento de padrões e aprendizado de máquina**.
Essa categoria inclui aplicações como **robótica, tomada de decisão, reconhecimento de imagem e voz, aprendizado de máquina e jogos**.

> **Resumo:** Software de IA utiliza técnicas inteligentes para resolver problemas complexos.
