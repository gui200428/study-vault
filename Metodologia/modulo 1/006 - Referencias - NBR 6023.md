
### Referência de livro

Para referenciar um **livro completo**, o padrão mostrado no material segue esta ordem:

> **SOBRENOME, Prenome. Título do livro: subtítulo. Edição. Cidade: Editora, ano.**

**Exemplo:**

> GALVÃO, Fernando. _Direito penal: parte geral_. 4. ed. Rio de Janeiro: Lumen Juris, 2011.

> **Livro = Autor → Título → Edição → Cidade → Editora → Ano**

> **Quem escreveu → qual livro → qual edição → onde → quem publicou → quando**

### Referência de livro eletrônico

Segue quase a mesma estrutura do livro convencional:

> **SOBRENOME, Prenome. Título: subtítulo. Edição. Cidade: Editora, ano.**

Depois, acrescenta-se a forma de acesso:

- **E-book / CD-ROM / outro meio eletrônico**; ou
- **Disponível em:** endereço eletrônico;
- **Acesso em:** dia mês ano.

**Exemplo:**

> FELITZEN, Cecília von; CARLSSON, Ulla. _A criança e a mídia: imagem, educação e participação_. São Paulo: Cortez, 2002. Disponível em: endereço eletrônico. Acesso em: 12 out. 2012.


> **Livro comum + onde acessar + quando acessou**

### Referência de capítulo de livro
Quando você usa **apenas um capítulo**, primeiro referencia o **autor e o título do capítulo**. Depois usa **In:** para indicar em qual livro aquele capítulo está.

Estrutura:

> **SOBRENOME, Prenome. Título do capítulo. In: SOBRENOME, Prenome. Título do livro: subtítulo. Edição. Cidade: Editora, ano. Capítulo, páginas inicial-final.**

**Exemplo simplificado:**

> STREET, Brian. A escolarização do letramento. In: STREET, Brian. _Letramentos sociais_. São Paulo: Parábola Editorial, 2014. Cap. 5, p. 121-144.

> **Capítulo primeiro → depois o livro onde ele está**


### Monografia, dissertação e tese
A referência deve indicar:


- **autor**;
- **título do trabalho**;
- **ano**;
- **tipo do documento**;
- **grau/curso**, quando aplicável;
- **instituição**;
- **local**;
- **ano da defesa**.

Estrutura:

> **SOBRENOME, Prenome. Título do trabalho. Ano. Tipo do documento (grau/curso) – Instituição, cidade, ano.**

**Exemplo:**

> SANTOS, C. M. D. _Identidades evidenciadas na fala-em-interação em aulas de alfabetização de jovens e adultos_. 2006. Dissertação (Mestrado em Linguística Aplicada) – Unisinos, São Leopoldo, 2006.

> **Monografia / dissertação / tese = identificar o trabalho + dizer que tipo ele é + onde foi defendido**


### Artigo de periódico

A referência deve trazer:

- **autor(es)**;
- **título do artigo**;
- **nome do periódico/revista**;
- **local de publicação**;
- **volume**;
- **número/fascículo**;
- **páginas inicial e final**;
- **data ou período de publicação**.

Estrutura:

> **SOBRENOME, Prenome. Título do artigo. Título do periódico, cidade, v. X, n. Y, p. XX-YY, mês/ano.**

**Exemplo simplificado:**

> ASSIS, Juliana Alves; LOPES, Maria Angela P. Teixeira. Ethos, discursos e representações na atividade de avaliação de textos escritos. _Scripta_, Belo Horizonte, v. 13, n. 24, p. 71-94, 2009.


> **Artigo primeiro → revista depois**

**Capítulo:** aparece **In:** + livro  
**Artigo:** aparece **nome do periódico/revista + volume + número**

### Relatório

A referência de relatório costuma trazer:

- **autor**;
- **título do relatório**;
- **cidade**;
- **instituição**;
- **ano**;
- **número de páginas**;
- indicação de que é um **relatório**.

Estrutura:

> **SOBRENOME, Prenome. Título do relatório. Cidade: Instituição, ano. Número de páginas. Relatório.**

**Exemplo:**

> BRASILEIRO, Ana Clara Matias. _Patentes analisadas na área da Saúde_. Belo Horizonte: UFMG, 2012. 17 p. Relatório.


### Documento de anais de congresso

Quando a referência é do **evento/congresso como um todo**, entram os dados do próprio evento:

- nome do evento;
- número da edição;
- ano;
- local de realização;
- título dos anais;
- cidade;
- instituição/editora;
- ano de publicação;
- volume/número;
- páginas ou volumes.

Estrutura:

> **NOME DO EVENTO, número, ano, cidade. Título dos anais. Cidade: Instituição, ano.**

**Relatório = quem fez + relatório + instituição**  
**Anais = qual evento + quando/onde aconteceu + publicação do evento**


### Anais de congresso em formato eletrônico

A estrutura básica continua sendo:

- **nome do evento**;
- **número da edição**;
- **ano**;
- **local de realização**;
- **título dos anais**;
- **cidade/instituição responsável**;
- **ano de publicação**.

Por ser eletrônico, acrescenta-se:

- **tipo de meio eletrônico**, quando aplicável;
- **Disponível em:** endereço eletrônico;
- **Acesso em:** dia mês ano.

Estrutura resumida:

> **NOME DO EVENTO, número, ano, cidade. Título dos anais. Cidade: Instituição, ano. Disponível em: endereço eletrônico. Acesso em: data.**

> **Anais eletrônico = anais normal + link + data de acesso**


### Legislação
Abrange documentos legais e normativos, como:

- Constituição;
- emendas constitucionais;
- leis;
- medidas provisórias;
- decretos;
- resoluções;
- portarias;
- instruções normativas;
- outros atos oficiais.
> **Legislação = Constituição + leis + decretos + atos normativos**

### Referência de legislação

Ela costuma incluir:

- país, estado, município ou órgão responsável;
- tipo da norma;
- número da norma;
- data;
- título ou ementa, quando houver;
- dados da publicação.

**Exemplo:**

> BRASIL. Lei nº 9.887, de 7 de dezembro de 1999. ...


### Legislação em formato eletrônico

Além dos dados anteriores, acrescenta-se:

- **Disponível em:** endereço eletrônico;
- **Acesso em:** dia mês ano.

**Exemplo:**

> BRASIL. Constituição da República Federativa do Brasil de 1988. Brasília, DF: Presidência da República. Disponível em: endereço eletrônico. Acesso em: 20 mar. 2020.


> **Lei = quem publicou + qual norma + número + data**

se for online:

> **+ link + acesso**


|Tipo|Estrutura resumida|Lembrete rápido|
|---|---|---|
|**Livro**|Autor → Título → Edição → Cidade → Editora → Ano|**livro = autor + publicação**|
|**Livro eletrônico**|Livro normal → Link/meio eletrônico → Data de acesso|**livro + onde acessou**|
|**Capítulo de livro**|Autor do capítulo → Título → **In:** → Livro → Páginas|**capítulo → In: → livro**|
|**Monografia / dissertação / tese**|Autor → Título → Ano → Tipo → Curso/Grau → Instituição → Local → Ano|**tipo do trabalho + onde foi defendido**|
|**Artigo de periódico**|Autor → Artigo → Revista → Volume → Número → Páginas → Data|**artigo → revista**|
|**Relatório**|Autor → Título → Cidade → Instituição → Ano → Páginas → Relatório|**quem fez + instituição**|
|**Anais de congresso**|Evento → Edição → Ano → Local → Título dos anais → Instituição → Ano|**referência do evento**|
|**Anais eletrônico**|Anais normal → Link → Data de acesso|**anais + onde acessou**|
|**Legislação**|Jurisdição/entidade → Norma → Número → Data → Título/Ementa → Publicação|**quem publicou + qual norma + quando**|
|**Legislação eletrônica**|Legislação normal → Link → Data de acesso|**lei + link + acesso**|


**Livro:** Autor → Título → Edição → Cidade → Editora → Ano

**Livro eletrônico:** Livro + Link + Acesso

**Capítulo:** Autor do capítulo → Título → **In:** → Livro → Páginas

**TCC / Dissertação / Tese:** Autor → Título → Tipo → Curso → Instituição → Local → Ano

**Artigo:** Autor → Artigo → Revista → Volume → Número → Páginas → Data

**Relatório:** Autor → Título → Instituição → Ano

**Anais:** Evento → Edição → Ano → Local → Publicação

**Anais eletrônico:** Anais + Link + Acesso

**Legislação:** Jurisdição → Norma → Número → Data → Publicação

**Legislação online:** Legislação + Link + Acesso
