## Classe:

→ Classe tem nomes e atributos
→ Métodos: Especificar as características comportamentais de uma classe. (ex: função de definirNome())



![[Pasted image 20250930234413.png]]


### Visibilidade 

→ Normalmente os atributos são privados
→ Métodos são publicos

![[Pasted image 20250930234511.png]]

### Relacionamento

**Herança →**
→ Relação entre classe principal e secundaria
→ Usado para não se repetir, uma classe secundaria herda os atributos da classe principal

![[Pasted image 20250930234726.png]]


**Associação: —**

→ Associar classes com palavras de ligação

![[Pasted image 20250930234938.png]]

**Agregação:**

→ Tipo de relacionamento que indica que uma classe pode fazer parte de uma maior, mas pode existir sozinha.

![[Pasted image 20250930235144.png]]

**Composição:**

→ Objeto secundário não pode existir sem o primário

![[Pasted image 20250930235332.png]]

**Multiplicidade:**

→ Indica unidade de uma classe secundaria, com relação a principal.

![[Pasted image 20250930235511.png]]
